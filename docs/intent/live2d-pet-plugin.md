# Intent: Live2D 宠物插件

Confirmed intent（已经用户确认的方向）。

## Outcome

为 DSH Web GUI 提供一款**实用陪伴型** Live2D 桌宠插件：宠物成为 Agent 状态镜像（思考 / 工作 / 空闲 / 出错动画与气泡）+ 互动陪伴（摸头 / 点击 / 任务完成庆祝），内置**策展模型 URL 清单**（纯 URL 直载、不随包分发，默认 Hiyori），支持用户通过设置面板**添加自定义模型**。

内置 DSH 设置面板「桌宠配置」tab（`settings.section`），四项设置：**开关 / 尺寸滑杆 / 模型列表 / 调试模式**；配置持久化经 `ctx.settings`（`$DSH_HOME/settings.yaml`，用户层覆盖 cordis.yml base 配置）。

## User

- DSH 重度用户（开发者）：长任务等待期的陪伴与状态感知
- DSH 潜在新用户：作为产品差异化与情感化卖点吸引

## Why now

- DSH 需要从"纯工具"走向"有性格的工具"，桌宠是低成本高感知的差异化
- Agent 长任务执行期的等待是真实 UX 空白，宠物可同时承担状态可视化
- Live2D Web 技术栈成熟（Cubism Web SDK / pixi-live2d-display），浏览器内可运行
- 中文开发者社区对桌宠/看板娘文化接受度高（live2d-widget 等先例）

## Success

1. 插件可安装到 DSH Web GUI，宠物正常渲染、交互、不干扰工作
2. 状态镜像准确：思考 / 工作 / 空闲 / 出错动画与气泡与 agent 状态一致
3. 互动可玩：摸头、点击反应，任务完成有庆祝反馈
4. 设置可达：设置面板「桌宠配置」tab 四项设置（开关/尺寸滑杆/模型列表/调试模式）生效并持久化；模型列表内置只读、自定义可增删改且可选中加载
5. 模型清单条目**许可可标注**（每条记录许可类型与链接；NC 模型标注"仅限非商用"）；默认模型商用安全（Hiyori）；无随包分发风险
6. 留存指标：重度用户持续启用（启用时长 / 关闭原因可观测）

## Constraint

- **许可合规（降低门槛）**：模型清单条目只需**许可可标注**——记录许可类型与链接即可收录，不做许可合规判断；NC（禁止商用）模型可收录但必须标注"仅限非商用"；默认模型保持商用安全（Hiyori）；SDK 遵守官方条款（版权声明）；代码库避开 GPL 传染
- 性能：标签页隐藏时暂停渲染；低配机器回退静态头像
- 不打扰：小尺寸、默认右下角停靠、可拖动、可隐藏、可关闭
- 技术栈：Cordis 插件（Client 渲染 + Host 资产管理/状态事件），WebGL，DCH Web GUI Slot 注册；设置经 `ctx.settings`（base = cordis.yml 条目 config）

## Out of scope

- 完整通用 Live2D 运行时（任意模型全特性兼容）——MVP 只做策展 URL 清单 + 加载 URL
- **随包分发模型文件**（任何模型文件打进 npm 包）——模型一律 URL 直载，零分发
- 通知中心替代——后续增值，非 MVP
- 脱离页面的桌面宠物 / 独立窗口
- 自研建模与美术（依赖社区/第三方高质量模型）
- 设置面板范围外配置：可配置停靠角（固定右下角）、重置位置按钮、隐藏快捷键、尺寸三档（用连续滑杆）、自定义模型的全字段元信息（作者/许可/Cubism，自定义仅名称 + URL）
