# Intent: Live2D 宠物插件

Confirmed intent（已经用户确认的方向）。

## Outcome

为 DSH Web GUI 提供一款**实用陪伴型** Live2D 桌宠插件：宠物成为 Agent 状态镜像（思考 / 工作 / 空闲 / 出错动画与气泡）+ 互动陪伴（摸头 / 喂食 / 任务完成庆祝），内置宽松许可精选预设模型，支持加载用户自己的模型 URL。

## User

- DSH 重度用户（开发者）：长任务等待期的陪伴与状态感知
- DSH 潜在新用户：作为产品差异化与情感化卖点吸引

## Why now

- DSH 需要从"纯工具"走向"有性格的工具"，桌宠是低成本高感知的差异化
- Agent 长任务执行期的等待是真实 UX 空白，宠物可同时承担状态可视化
- Live2D Web 技术栈成熟（Cubism Web SDK / pixi-live2d-display），浏览器内可运行
- 中文开发者社区对桌宠/看板娘文化接受度高（live2d-widget 等先例）

## Success

1. 插件可安装到 DSH Web GUI，宠物正常渲染、交互、不干扰工作
2. 状态镜像准确：思考 / 工作 / 空闲 / 出错动画与气泡与 agent 状态一致
3. 互动可玩：摸头、喂食、点击反应，任务完成有庆祝反馈
4. 预设模型**许可合规**（明确可再分发、标注出处），无版权风险
5. 留存指标：重度用户持续启用（启用时长 / 关闭原因可观测）

## Constraint

- **许可合规为硬约束**：预设模型必须逐一核实可再分发；SDK 遵守官方条款（版权声明、必要时提交出版许可申请）；代码库避开 GPL 传染
- 性能：标签页隐藏时暂停渲染；低配机器回退静态头像
- 不打扰：小尺寸、四角停靠、可隐藏、可关闭
- 技术栈：Cordis 插件（Client 渲染 + Host 资产管理/状态事件），WebGL，DCH Web GUI Slot 注册

## Out of scope

- 完整通用 Live2D 运行时（任意模型全特性兼容）——MVP 只做精选预设 + 加载 URL
- 官方示例模型（式神等）作为内置预设——再分发受许可限制
- 通知中心替代——后续增值，非 MVP
- 脱离页面的桌面宠物 / 独立窗口
- 自研建模与美术（依赖社区/第三方高质量模型）
