# Intent 索引

记录**产品意图**：要达成什么、给谁用、为何现在做、如何算成功、约束与明确不做。

## 何时写

- 新功能或大改动启动前（意图已确认后落盘）
- 产品范围、成功标准或「不做清单」发生变化时

## 何时不写

- 纯实现细节、无产品意图变化
- 意图尚未与用户确认（先澄清，不要把推测写成 Confirmed）
