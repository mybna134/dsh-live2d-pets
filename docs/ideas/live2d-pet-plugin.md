# Live2D 宠物插件（DSH）

## Problem Statement

HMW 让 DSH 用户在等待 agent 长任务执行时，通过一个有性格、有功能性的 Live2D 桌宠获得**状态感知**与**陪伴感**，从而提升重度用户的留存与产品差异化？

## Recommended Direction

**实用陪伴款** = Agent 状态镜像 + 互动陪伴（1+3 结合）。

- **Client 侧**在 DSH Web GUI 的 Slot 里渲染 Live2D 宠物（WebGL，pixi-live2d-display / Cubism Web SDK），把 agent 状态映射成动画与气泡：思考中、工具调用中、空闲、出错、任务完成。
- **互动层**：拖动、摸头、喂食、点击反应；长任务等待期有可玩性，任务完成时庆祝（撒花/欢呼）。
- **Host 侧**：模型资产与预设管理、设置持久化、订阅 agent 状态事件并转发给 Client。
- **预设模型**：2-3 个**可再分发**的宽松许可社区模型（标注出处）+ 支持加载任意模型 URL。
- **不打扰**：小尺寸、四角停靠、可隐藏、标签页隐藏时暂停渲染、低配机器回退静态头像。

成功标准：**重度用户留存**（持续启用率），而非单纯下载量。

## Key Assumptions to Validate

- [ ] 能找到足够数量的"可再分发"高质量 Live2D 模型 —— 检索 GitHub / 社区宽松许可模型清单，逐一核对许可文本（重点：是否允许再分发与商用）
- [ ] 状态可视化提升留存而非打扰 —— 原型上线后观察持续启用率，可埋点统计启用时长与关闭原因
- [ ] WebGL 性能在主流机器可接受 —— 原型里测 FPS 与 GPU 占用，验证"标签页隐藏暂停渲染"降耗策略
- [ ] Cubism SDK 的署名 / logo 展示条款细节 —— 实现前核实[官方发布权限说明](https://help.live2d.com/zh-CHS/sdk/)，确保插件分发合规

## MVP Scope

**In：**

- 2 个精选预设模型（宽松许可，标注出处）
- agent 状态 → 动画映射（思考 / 工作 / 空闲 / 出错 + 状态气泡 + 任务完成庆祝）
- 基础互动：拖动、摸头、点击反应
- 设置项：开关、大小、四角位置、隐藏快捷键
- Host 侧：设置持久化 + 状态事件订阅

**Out（后续迭代）：**

- 加载任意模型 URL（放 MVP 后期或 v0.2）
- 社区模型市场 / 预设包扩展
- 通知中心替代（有性格的提醒）
- 游戏化养成系统

## Not Doing (and Why)

- **不做完整通用 Live2D 运行时**（v1/v2/v3 全特性、物理、表情动作组全覆盖）—— 工程量大，MVP 验证状态镜像假设不需要
- **不用官方示例模型（式神等）做预设** —— 再分发受许可限制，许可风险不可接受
- **不做通知中心替代** —— MVP 只做状态感知与陪伴，通知是后续增值
- **不做脱离页面的桌面宠物** —— 这是浏览器 GUI 插件，不引入独立窗口/托盘
