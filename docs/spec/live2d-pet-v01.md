# Spec: Live2D 宠物插件 v0.1

用户可感知行为规格。对应 Intent：[`../intent/live2d-pet-plugin.md`](../intent/live2d-pet-plugin.md)。
状态事件与挂载点基于实测（ADR-002）；渲染技术基于 ADR-001。

## 1. 概述

DSH Web GUI 中一只悬浮于角落的 Live2D 桌宠，实时镜像当前会话 agent 状态（思考/空闲/出错/完成），支持摸头与点击互动、任务完成庆祝；内置 2 个宽松许可预设模型，支持加载用户自备模型 URL。默认开启、默认右下角、小尺寸、可一键隐藏。

## 2. 启用与设置

- 插件启用后宠物默认显示在**右下角**，小尺寸
- 设置项（持久化，经 `settings` 插件配置入口）：
  - 开关（显示/隐藏）
  - 尺寸：小 / 中 / 大
  - 停靠位置：左下 / 右下 / 左上 / 右上
  - 隐藏快捷键（默认可配置）
  - 模型选择：预设模型 A / 预设模型 B / 自定义 URL
  - 调试模式开关（开发用，默认关）：开启后显示调试面板
- 调试面板（debug 开启时显示）：实时 agent 状态、宠物当前状态/动画、模型信息（尺寸/缩放/命中区名）、最近气泡、错误日志、FPS；提供「演示状态」切换（强制 空闲/思考/完成）用于测试状态机；与宠物同顶层容器（ADR-005），关闭时零渲染
- 宠物悬浮菜单（右键或悬浮时出现）：隐藏、设置、切换到空闲/思考演示动画（调试用）

## 3. 状态镜像（核心）

状态机五态，映射到真实 DSH 事件（ADR-002）：

| 宠物状态 | 触发事件 | 表现（动作/表情 + 气泡） |
|----------|----------|--------------------------|
| 空闲 | `agent/status` status=idle（非刚完成） | 待机动画（眨眼/呼吸/发呆）；偶发气泡（"在呢~""摸鱼中…"） |
| 思考中 | `agent/status` status=running | 歪头/敲键盘动画；气泡（"思考中…""让我想想"） |
| 出错 | `agent/error` | 委屈表情；气泡（"出错了，要我帮你看看吗？"） |
| 完成 | `agent/turn-stopping` + running→idle 下降沿 | 欢呼/撒花动画；气泡（"搞定！"） |
| （可选）等审批 | `approval/request` | 张望动作；气泡（"等你拍板~"） |

- 状态变化即时反映（事件驱动，无轮询延迟感知）
- 气泡文案风格：**中文活泼卖萌**；文案池常量内置（v0.1 不做自定义）

## 4. 触摸互动

- **点击身体**：随机反应动作 + 随机气泡（"嘿嘿~""再点我就要生气了哦"）
- **摸头**（命中模型头部命中区域 Hit Area）：专属享受动作 + 气泡（"摸头舒服~"）
- **拖动**：可拖动到任意位置，松手后吸附到最近的角落停靠位
- **防刷屏**：交互气泡冷却 2 秒（冷却期内只做动作不出气泡）
- 互动动画可打断当前状态动画，结束后回到当前状态对应的动画

## 5. 任务完成庆祝

- 触发：思考中 → 空闲 的下降沿（一轮工作结束）
- 表现：欢呼/撒花动画 + "搞定！"气泡，持续约 3 秒后回到空闲态
- v0.1 不含音效（资源与许可成本，v0.2 再议）

## 6. 预设与模型加载

- 内置 **2 个预设模型**：均为明确可再分发的宽松许可（如 CC-BY 或作者明示允许再分发）
- 每个预设展示：模型名称、作者、许可类型与许可链接（点击可查看）
- **自定义 URL 加载**：设置中输入 `.model3.json` 的 URL 加载用户自备模型（零许可风险路径）
- **加载失败兜底**：显示静态头像占位 + 错误气泡提示，不影响 GUI 其它功能；可从设置重新加载

## 7. 性能与不打扰

- 标签页隐藏 / 窗口失焦：暂停渲染循环（保留最后画面），恢复时继续
- WebGL 不可用或 FPS 持续过低：自动降级为**静态头像模式**（不启动渲染循环）
- 一键隐藏后完全不渲染（零开销）；隐藏状态持久化
- 默认小尺寸、右下角，不遮挡对话主操作区；可随时拖动/关闭

## 8. 验收要点

- [ ] 启用后宠物出现在右下角，可拖动并吸附四角
- [ ] agent 思考/空闲/出错/完成时，动画与气泡与状态一致（用真实事件触发验证）
- [ ] 摸头命中头部区域触发专属反应；点击身体触发随机反应；连点 2 秒内有冷却
- [ ] 完成庆祝动画在任务结束后出现并回到空闲态
- [ ] 2 个预设模型许可信息可见；输入 URL 可加载用户模型；加载失败显示静态头像
- [ ] 标签页隐藏后渲染暂停；WebGL 不可用时为静态头像
- [ ] 设置项（开关/尺寸/位置/快捷键/模型）生效并持久化
- [ ] debug 开关生效：开启显示调试面板、关闭零渲染；「演示状态」切换可强制宠物状态

## 9. 技术边界（实现约定，非用户行为）

- 渲染：pixi-live2d-display 0.4.0 + PixiJS 6.5.10 + Cubism Core 4（ADR-003；ADR-001 已被其取代）
- 挂载：Client Slot `shell.overlay`；设置入口 `settings.plugin.item` / `settings.section`（ADR-002）
- 状态源：Host 订阅 `agent/status`、`agent/error`、`agent/turn-stopping` 等（ADR-002）
- 预设模型许可合规为硬约束；SDK 按 Live2D 官方条款
- **spike 结果（见 ADR-003）**：WebGL ✅ / DOM·script 注入 ✅ / CDN 脚本加载 ✅ / Host→Client 轮询 ✅ / 模型渲染 ✅ / 动作·表情 ✅ / 触摸命中 ✅；Cubism 5 兼容未验证
- **待定项（承接自 ideas 草稿，已并入）**：
  - 插件分发/安装形态：cordis.yml 插件行 vs marketplace vs npm 包（决定交付物结构）
  - 模型资产托管方式：随包内置 vs 首次使用时远程拉取（影响安装体积）
  - 预设模型许可清单逐一定稿：2 个预设逐一核对"可再分发"许可文本，定稿许可卡片内容（§6 硬约束）

## 10. v0.1 明确不做

- 喂食/养成玩法（v0.2）
- 通知中心替代
- 完整通用 Live2D 运行时
- 音效、自定义文案池、模型市场
