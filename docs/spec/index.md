# Spec 索引

记录**行为规格**：用户可感知的行为、规则、边界与验收要点。供实现与回归对照。

## 何时写

- 用户可感知行为将发生变化或新增时（实现前写清，实现后保持同步）
- 已有 spec 覆盖的细节被改动时（即使是小改也要顺手更新）

## 何时不写

- 纯样式 / 文案 / 内部重构且行为不变，且现有 spec 未描述相关细节
